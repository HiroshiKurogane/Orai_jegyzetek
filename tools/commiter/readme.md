# Auto commiter and inicializer

## Auto init
The auto init file only sets up a few things for the auto commiter.
You have to make a folder called "repo" where the auto init file is.
It will make a .init file that only exist because atleast 1 file is needed to set up the local repository.

## Auto commiter
This will automaticly add and commit the changes you made on your local repo.
You may add your own commit message in the beggining or just leave it empty. (in that case the commit message will  be "automatic update")
**This program does not pull any data from the repo,** so before you use it please pull the changes your teammate or you did before running it.
run **git pull** in your repo folder
